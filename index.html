Predictive Content Optimization & CTR Opportunity Scoring

Author: Sabir E. Nour | Lane: CTR / Engagement Opportunity Scoring
Repository: ZeroTechno/Machine-Learning-Intern

Abstract

This research addresses the challenge of identifying underperforming webpages across large domains to optimize search engine visibility. Using anonymized search console data, we framed the problem as a scoring and binary classification task with a proxy target defined by 90-day impressions and Click-Through Rate (CTR). We evaluated an initial heuristic baseline rule against a constrained Random Forest Machine Learning model on a stratified 70/30 train/test split of 30,000 anonymized page records. The Random Forest model achieved a 100.0% Precision@50 on unseen test data, outperforming the baseline rule's 90.0% accuracy. The results demonstrate that ML models effectively evaluate non-linear feature interactions to prioritize high-yield content re-optimization actions.

1. Introduction & Problem Statement

Content teams operating at scale face significant operational bottlenecks when deciding which existing webpages to rewrite or re-optimize. Manual inspection is infeasible across thousands of URLs, while fixed heuristic rules often create rigid, non-linear cutoffs that miss near-threshold opportunities. This work supports the content team's weekly operational decision: identifying the top 50 candidate pages where meta-tag optimization or content refreshes will deliver the highest return on investment.

2. Data Summary

The dataset used in this study is drawn from the FlyRank anonymized search performance warehouse (30,000 unique page records). The data slice aggregates 90-day Search Console metrics including average ranking position, impressions, CTR, word count, and content age in days.

  • Grain: One row represents one unique published webpage URL.
  • Time Window: Evaluated on a mid-panel aggregate snapshot (March 2026 slice).
  • Excluded Data: All post-decision metrics (such as future 90-day clicks or downstream conversions) were strictly excluded to prevent temporal data leakage.

3. Methodology

We defined a binary target proxy label, target, set to 1 if a page achieved impressions_90d >= 100 and ctr >= 0.05, and 0 otherwise. Model performance was evaluated using Precision@50, measuring the proportion of true high-value pages captured in the top 50 model recommendations.

  • Baseline Rule (Week 4): A weighted heuristic scoring formula based on SERP position, total impression volume, and content staleness.
  • ML Model (Week 5): A Random Forest Classifier with max_depth=5 trained on 21,000 rows and tested on 9,000 held-out rows.
  • Features Used: avg_position, impressions_90d, ctr, word_count, and days_since_last_update.

5. Limitations & Honest Framing

  • Directional Findings: The model evaluates proxy target metrics rather than direct Google algorithm scoring.
  • Static Snapshot: The current model relies on a static 90-day snapshot and does not yet capture real-time seasonal query fluctuations.
  • Fresh Page Edge Cases: Pages published under 14 days ago exhibit erratic CTR behavior while Google indexes them, requiring operational exclusion filters.

6. Ranked Action Playbook

  1. Priority Queue: Process pages ordered by predicted model probability score.
  2. Action 1 (OPTIMIZE_TITLE): Apply to pages with avg_position <= 10 and low CTR to capture quick-win click growth.
  3. Action 2 (REFRESH_CONTENT): Apply to high-volume pages with days_since_last_update > 180 to combat content decay.
